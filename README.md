Entry for the [Angry Judge: The Short Rant Contest](https://make.fun/competitions/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on [make.fun](https://make.fun).

`main.py` writes one short, funny rant (max 400 characters) about an
everyday annoyance — a slowly sinking office chair — to `/output/entry.txt`.
Deterministic, no network, no randomness.

Run it with:

```sh
python3 main.py
```
